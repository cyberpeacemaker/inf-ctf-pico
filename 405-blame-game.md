# Git Version
### Summary: Which tool to pick?

* **"Who wrote this specific line?"** $\rightarrow$ `git blame`
* **"What has happened to this file since Monday?"** $\rightarrow$ `git log -p --since="Monday"`
* **"What did I just change before I commit?"** $\rightarrow$ `git diff`
* **"What is the difference between my version and the master branch version?"** $\rightarrow$ `git diff master -- [filename]`
